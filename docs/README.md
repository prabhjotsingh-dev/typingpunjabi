# TypingPunjabi Wiki

Welcome to the **TypingPunjabi Wiki**!

This wiki serves as the central documentation hub for the project, primarily focusing on recording challenges, problems encountered during development, and their respective solutions. 

By documenting our problem-solving process, we aim to:
- Avoid repeating the same mistakes.
- Onboard new developers more easily.
- Keep a historical record of technical decisions.
